# ISM2411 Lab 12 — Read a Sales CSV, Write a Cleaned Report

Talmer Brown

Run from the repository folder with Python 3:

```bash
python3 csv_practice.py
```

The script covers Exercises 1–8 and includes both reflection responses at the top.
It reads `data/sales.csv`, regenerates `data/cleaned.csv`, and appends one timestamped
entry to `data/run_log.txt` each time it runs. The committed log contains three runs.

Source: https://markumreed.github.io/ism2411/assets/downloads/sales.csv
